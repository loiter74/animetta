# 鲸鱼女仆 Live2D 第一版

全身、长发、深蓝长袖女仆服。保留 `standard`（标准微笑）和 `goofy`（傻笑）两种表情。

预览地址：`/live.html?review=1&scene=empty&avatar=whale-maid-v1`。调试控件与状态标签位于 `/dashboard` 的“验证 → 立绘调试”：可切换表情、模拟情绪、运行有界口型演示，以及按 25% 步长缩放至 100%–300%；“全身”恢复初始比例。后台复用正式直播入口的静音隔离预览，手动操作只影响该预览。直播画面不显示调试控件。当前默认模型仍由模型配置选择。

正式直播入口固定使用 3840×2160 UHD 渲染画布，与设备 DPR 和浏览器侧栏尺寸无关。16:9 视口显示完整画面，较窄窗口按中心裁切预览，保持人物比例与高度；不支持该画布尺寸的图形上下文会报告加载失败。普通伙伴窗口继续使用响应式高 DPI 渲染。4K 输出不代表当前 1024×1536 原画已经成为 4K 原生素材，面部分层与原画精修仍在继续。

## 文件

- `whale-maid-v1.model3.json`：运行入口；同目录包含真实 Cubism `.moc3`、贴图、物理、动作及两份表情文件。
- `source/whale-maid-v1.psd`：21 个实际素材图层，包含独立眼裂、眼框、虹膜和肩颈补底，可继续修画。
- `source/whale-maid-v1.cmo3`：包含第一版网格、参数、形变和层级的可编辑工程。
- `source/standard.png` / `goofy.png`：用户确认的完整立绘。
- `source/face-underpaint.png` / `blink.png`：补画来源。面部底色仅取脸部区域，外圈半透明像素不用于成品。
- `source/iris-pair-anime-v3.png`、相邻提示词与 `iris-provenance.json`：内置 image_gen 生成的透明蓝色圆瞳原始素材与来源记录。
- `source/rig-validation.json`：本版源文件哈希、眼部遮罩角色、几何验证范围和剩余限制。

## 生成与绑定

原画及局部编辑使用内置 image_gen：成年等身全身、蓝青渐变长发、鲸鳍耳和鲸尾、收腰深蓝长袖女仆裙、白围裙、金色袖饰和蓝色菱形胸针。标准版为闭嘴微笑；傻笑版保留相同造型，使用半眯眼和张口笑；另外补画无五官面部底色及闭眼睫毛。

使用 [PSD2Live 3.4.5](https://github.com/tsunehimatoi/psd2live/releases/tag/v3.4.5) 原生素材分割、PSD 导出、网格生成和工程编辑。肩颈补底取自同一原画的连续区域，放在已有头发和身体图层之下。眼部切分后通过独立 NEW 项目保存、导出完整 21 网格工程，避免 REPLACE 导入重复 atlas 槽。当前实际运行贴图为 13 页；目录名 `.2048` 不代表每一页的实际尺寸。导出器仍可能清空 MOC 页号，因此按完整源 CMO3 的资源哈希及 UV 建立 `source/texture-pages.json`。在本模型目录运行 `node source/restore-texture-pages.cjs` 可恢复并校验页号；不能复用旧版 17 网格清单。制作工具不作为 Animetta 的运行依赖，物理以同目录 `physics3.json` 为准，重新导出不能用工具默认物理覆盖它。

`ParamMouthOpenY` 驱动嘴型；`ParamEyeLOpen` / `ParamEyeROpen` 独立驱动两眼开合。模型包含 31 个参数，已有八组局部增量形变为双侧鲸鳍耳 `ParamFinR/L`、三束前发 `ParamHairFringeR/C/L`、双臂 `ParamArmR/L` 和裙摆 `ParamSkirtSway`。本版新增双手腕 `ParamHandR/L`：手部绕腕关节约 ±6°，袖口固定，并与手臂／裙摆增量组合；99 个相关姿势无新增可见翻折或退化，手部端点最大位移约为原画 11.5 像素。这不是逐指绑定。

Idle 包含呼吸、眨眼、鲸尾、鲸鳍、双臂、轻微手腕动作与带停留的视线漂移。三束前发、裙摆和背发由唯一物理阶段驱动；Idle 不重复写入它们。播放器额外呼吸层保持关闭，待机不驱动头部旋转。Nod / Shake 仅用于显式语义动作。

Animetta 按模型配置把现有 SDK 的唯一物理阶段改为 60Hz 固定步进，并插值显示输出；输入／输出清单直接取自实际物理 rig。插值结果不回灌模拟，暂停页面恢复时最多追赶 0.25 秒；其他模型保留原行为。实际 SDK 与当前成品 Core 的 30／60／120FPS 检查中没有新增可见翻折或非有限坐标，物理输入没有被改写；60 与 120FPS 公共采样点一致，30FPS 连续呼吸采样的最大参数差约为峰峰值的 2.59%。当前物理待机在原画坐标中的前发／裙摆最大位移约为 0.61／1.64 像素，属于轻微联动。

八组局部形变的几何增量已扩大为此前版本的 2 倍，原有默认形、参数范围、UV 和三角形索引保持不变。真实 Cubism Core 的八轴 6,561 种端点／中性组合未出现新增翻折、退化或非有限坐标；3 倍候选会使左鲸鳍附近翻折，因此未采用。前发、双臂和裙摆的端点幅度分别约为原画 2.8–3.5、6.9–7.7 和 10.2 像素，这些是手动端点幅度，不是待机幅度。

傻笑口腔保留 75 个顶点、96 个三角形；闭嘴关键帧使用有面积的隐藏网格，透明度为零，避免导出器删掉共线口腔的三角形。双眼现在分别包含眼裂遮罩、眼框睫毛、完整虹膜与闭眼层；`ParamEyeBallX/Y` 只移动虹膜，按同侧眼裂裁切。半闭时不叠加旧闭眼睫毛，完全闭眼时虹膜与眼裂透明度为零。2,847 个连续开合／九格视线／头部组合姿态零翻折、零退化；仅删除一个纹理区域完全透明的切分细三角形，没有合并顶点或改变可见眼形。真实 SDK、固定物理与本版 MOC 的 24 秒 30／60／120FPS 集成检查通过，闭眼隐藏与实际浏览器遮罩另行检查。

Animetta 的模型配置将傻笑静息口型设为 0.82，并继续叠加说话开合。`.exp3.json` 保留眼神差异；其他播放器若只加载表情文件，需要同时设置静息口型才能得到同样的张口傻笑。

公开 `chat:expression` 与流式音频的情绪经当前回合校验后进入共享表情控制器，再由模型配置的 `emotionExpressions` 选择已有表情。当前开心使用 `goofy`，平静及其余尚无独立素材的情绪使用 `standard`；不额外调用模型推断情绪。后台手动选择优先，恢复自动时立即采用最新情绪。旧回合、停止与断线不会复活过期表情；口型、动作与表情选择保持独立。

## 第一版范围

已拆分头、躯干、背发、鲸尾、眉、双眼的眼裂／眼框／虹膜、闭眼和两种嘴型，并补上肩颈底层。本版完成双眼局部绑定和手腕动作，尚未完成商业级最终精修：大角度转头的头发和肩颈仍有裁切边；原画轻微歪头仍保留。`source/face-direction-v2.png` 是用户新参考图对应的标准／傻笑面部方向稿，本次只据其风格重画蓝色圆瞳，脸型原画尚未替换。后续脸型需保持清爽少女感、柔和小下巴与明亮眼神，不能靠拉长头部形变替代重画。
