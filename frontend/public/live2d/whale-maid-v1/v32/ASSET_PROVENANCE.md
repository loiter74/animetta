# V32 素材来源

本版本沿用本项目已确认的成年等身鲸鱼女仆原画及原生绑定，局部通过内置 image_gen 制作干净后发和颈根皮肤补画。生成时未显式指定模型版本。原始生成 PNG 保留 alpha，不使用脚本涂改或裁切生成像素。

`source/material-provenance.json` 保存具体输入、提示词、注册画布范围和 SHA-256。`source/backhair-L.png`、`source/backhair-R.png`、`source/neck-underpaint.png` 为选定的原始补画字节。运行图集由 PSD2Live 3.4.5 官方导出链生成；增加补画后发生合法 UV／页布局重排，已有材质另经真实 UV 与 PNG 采样核对。

本版本未下载或转用第三方成品 Live2D 模型。Cubism Core 与现有播放器属于独立运行依赖，沿用仓库既有分发与许可说明。这里记录素材制作来源，不将角色参考图或软件许可解释为额外的商标、角色授权。
